# ASTERIA-7

围绕同一艘虚构飞船 ASTERIA-7 的三个单文件浏览器实验。每个都是一个 `.html` 文件：用较新的 Chrome、Edge、Firefox 或 Safari 打开即可运行，无需构建，也无需安装。

| 文件 | 内容 | 使用的库 | 能离线吗？ |
|------|------------|-----------|----------|
| `spaceship-anime.html` | 滚动式动画展示：发射序列、随滚动自己画出来的蓝图、带变形路径的轨道、舰队编队、小型飞行员 / 小行星游戏、超空间跳跃 | anime.js 4.5.0（内嵌在文件中） | 可以 |
| `asteria-7-flight-v1.html` | 第一人称 3D 飞行演示：带景深的驾驶舱、泛光、镜头光晕、程序生成的行星、超空间跳跃 | 来自 jsDelivr 的 three.js 0.186.1 + anime.js 4.5.0 | 不能，需要联网 |
| `asteria-7-game.html` | 完整游戏：任务、升级，以及在真实地形上无缝着陆 | 来自 jsDelivr 的 three.js 0.186.1 + anime.js 4.5.0 | 不能，需要联网 |

## 游戏（`asteria-7-game.html`）

你从 Halo 空间站出发。在任务板上接任务、飞行执行、赚取点数并升级飞船。

- **任务：**
  - **运送：** 降落在太空港或与空间站对接。
  - **勘测：** 在区域内飞行到 5 公里以下，直到扫描完成。
  - **救援：** 降落在求救信标附近，再把幸存者带回来。
- **升级：** 引擎、船体、跳跃引擎和扫描仪，每项三级。
- **可着陆的星球：**
  - Aurelia（海洋）
  - Selene（卫星）
  - Vesper（熔岩）
  - Nivalis（冰）

  Kharon 是气态巨行星：没有可着陆的地方，深潜会损伤船体。
- **损伤：** 猛烈撞击会损伤船体。船体归零时飞船损毁，你会在空间站重生，并损失 15% 的点数。
- **存档：** 进度保存在浏览器的 `localStorage` 中。

### 操作

| 输入 | 动作 |
|-------|--------|
| 按住鼠标左键并拖动 | 转向（松开后回正） |
| W / S、鼠标滚轮 | 油门 |
| A / D | 翻滚 |
| R / F | 爬升 / 下降 |
| Shift | 加速 |
| P | 自动驾驶前往当前追踪的任务（在着陆台上方 1 公里处停下） |
| J | 超空间跳跃到导航目标 |
| T / N | 下一个导航目标 / 下一个追踪任务 |
| E | 互动（着陆后打开太空港） |
| C | 驾驶舱 / 外部视角 |
| B | 切换景深对焦 |
| X | 全停 |
| M | 声音开 / 关 |
| H | 隐藏 HUD |
| Esc | 暂停 |

触屏设备会显示屏幕上的摇杆和按钮。

**着陆：** 速度降到约 30 m/s 以下，保持飞船水平，并按住 **F**。当速度、角度和下降率都安全时，HUD 上的着陆检查表会变绿。外部视角（**C**）更容易看清地面。

### 无缝着陆是怎么做到的

- 从远处看，行星是用 3D 单纯形噪声在着色器里上色的球体。
- 靠近岩石星球时，飞船下方会生成三层嵌套的地形块：粗、中、细，最细约每格 100 米。每一层都分成小时间片重建，帧率不会卡顿。
- CPU 用与 GPU 上色相同的噪声计算地形高度。JavaScript 版本把每一步都舍入为 float32（`Math.fround`）。没有这一步时，约 40% 的采样点与着色器不一致；加上之后，256 个点全部吻合，所以海岸线和山脉与从轨道上看到的星球对得上。
- 对数深度缓冲让一个场景同时容纳米级（驾驶舱、地面）和数十万公里级（其他行星）的距离。
- 内部分辨率会自动调整，以保持约 60 fps。

## 已知限制

- 在极低高度时地形是平滑的，没有树木和建筑。
- 在 Windows、Intel UHD 630 集成显卡上测试过：开启自适应分辨率后约 60 fps。没有在手机或其他显卡上测试过。
- 两个 three.js 文件从 `cdn.jsdelivr.net` 加载库，所以需要联网。
